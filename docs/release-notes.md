Glint is a native macOS menu-bar window manager inspired by Spectacle.

This archive targets Apple silicon (arm64), with macOS 14 as its build minimum. Intel is not included. See INSTALL.md for installation, checksum verification, manual updates, rollback and removal.

The app uses a free ad-hoc signature. It has no Apple Developer ID signature or notarization; macOS approval and Accessibility permission are required. Managed Macs may block installation. Updates are discovered only on request and never installed automatically. Replacing an ad-hoc build can require granting Accessibility again.

Spectacle attribution is included in THIRD_PARTY_NOTICES.md. Glint's product license must be settled before the first publication; replace this preparation note with the accepted terms and tested OS matrix before enabling the first main-branch publication.
