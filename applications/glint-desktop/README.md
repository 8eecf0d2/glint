# Glint desktop

Native SwiftUI menu bar and Settings scaffold, macOS 14+, built with SwiftPM. Open Package.swift in Xcode or run `npm run dev:desktop` from the root. No paid developer account is required. The current bundle only displays defaults; no global hotkeys, Accessibility prompts, login item or movement logic are implemented.

The packaging script builds the host architecture only and applies a free ad-hoc signature. Universal release artifacts, a stable update identity and download installation testing remain release tasks. The app is not sandboxed. The provisional stable bundle ID is `dev.8eecf0d2.glint`.
